# WeatherAppTest

iOS-приложение погоды на Swift с использованием UIKit и SnapKit. Интерфейс собран полностью программно, без storyboard.

## Технологии

- **UIKit** — интерфейс
- **SnapKit** — Auto Layout
- **WeatherAPI** (weatherapi.com) — данные о погоде
- **Core Location** — геопозиция

## Запуск

1. Открыть `WeatherAppTest.xcodeproj` в Xcode.
2. Выбрать симулятор или устройство, запустить (⌘R).
